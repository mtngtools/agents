# create-issue-commit

Create appropriate GitHub issue using `gh` for uncommited changes. Commit current changes as a WIP commit.

Then commit the changes. You MUST follow the [draft-commit-message](../draft-commit-message/SKILL.md) skill to draft the commit message.
